Job Description

  • Day-to-Day Work:
    • Write and review code in languages like Python, Java, C++, or JavaScript.

    • Document code and maintain version control (e.g., Git).
  • Specializations:
    • Front-end (user interfaces and experience)
    • Back-end (servers, databases, systems logic)
    • Full-stack (both front and back end)
    • Mobile apps, game dev, cloud/AI, or cybersecurity-related software
